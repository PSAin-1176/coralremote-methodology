# Sample Config Notes

- `RAW_DIR` should point to the local folder that would contain files like the sample dates above.
- `ACA_DIR` should point to local ancillary inputs such as masks and polygons.
- `OUT_ROOT` should point to the local output root used by the runner.
- `PREP_SOURCE_ROOT` should point to local prepared-source products outside Git.
- `MASTERLOG_DIR` should usually be inside `OUT_ROOT`.
