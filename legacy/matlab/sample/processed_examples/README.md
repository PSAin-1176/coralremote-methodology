# Processed Example Policy

This folder may contain a very small number of curated processed example outputs.

## Allowed

- tiny baseline mask examples
- tiny classification map examples
- tiny confidence map examples
- small preview PNGs that explain output structure
- lightweight metadata files describing the examples

## Not allowed

- PlanetScope RAW imagery
- full-scene processed rasters
- large `.mat` datasets
- full run outputs
- private polygon datasets
- anything that recreates the working archive

## Rules

- keep files small
- prefer cropped or toy examples over full products
- use this folder for demonstration only
- every included file should be safe to publish publicly
