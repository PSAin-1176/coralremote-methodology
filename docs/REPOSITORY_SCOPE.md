# Repository Scope

This repository is scoped to the methodology pipeline only.

## Included

- preprocessing scripts
- baseline construction scripts
- main classification scripts
- evaluation helpers kept as secondary code
- shared utilities
- public path template and repository docs

## Excluded

- PlanetScope RAW imagery
- processed `.mat` datasets
- model files
- generated outputs and figures
- draft notes
- machine-local configuration
- local archives and run folders

## Code Layout

- `code/01_preprocessing`
- `code/02_baseline_construction`
- `code/03_classification`
- `code/04_evaluation`
- `code/utils`

## Publication Rule

GitHub should contain code and lightweight documentation only.
All data and run outputs stay outside the repository.
